# Missing Accessibility Identifiers for E2E Maestro Flows

Per project E2E convention (`docs/release/cb64-maestro.md`), Maestro YAML flows use only `.accessibilityIdentifier` values that exist in `App/` code. Every missing interactive or assertion target discovered while authoring the 18 flows under `e2e/maestro/` is recorded here instead of guessing identifiers.
