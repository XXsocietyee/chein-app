# i18n r1: English (US) launch alongside Chinese (2026-11-27)

Owner 11-27: the player version launches in China and in the US at the same time, with English. Every text must read well in both languages; Chinese and English lengths differ, so layouts must not truncate, overlap or distort.

Repo `https://github.com/XXsocietyee/chein-app`, base newest `origin/ui/combined-r7`. Native Apple components; no story-flow theme work. Merchant screens are out of scope (player + clubs only).

**Baseline (11-27):** `Resources/Localizable.xcstrings` 19,770 keys, 0 missing en. Problems: 34 en values contain Chinese (e.g. `club.gov.compensationGate`, `compliance.reviewWarning`, `compliance.typeToConfirm`, `couponManagement.dateNotice`); 45 App files hard-code Chinese in `Text("…")`; widget catalog `LiveActivityWidget/Localizable.xcstrings`; `InfoPlist` permission texts; `Core` `W8Text.t(zh, en)` strings.
