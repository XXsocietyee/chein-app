## OWNER RULE (11-27 12:50 UTC) — applies to EVERY lane, every page
"The complete page needs to be based on the mini-program, and then optimized based on the mini-program page."
1. **Base = the MP page.** Before touching any screen, open its MP page in `origin/mp-source:chengyinhub-xcx` (`.wxml` structure, `.wxss` sizes/colours, `.js` data, states, navigation). The native screen must contain every MP section in MP order, every field, the MP empty / loading / error states, the MP copy (translated for en), and the same navigation targets.
2. **Then optimize on top of it:** native Apple components, Dynamic Type, P1–P20 from `design-principles.md`, both languages. Optimizing never removes, merges away or reorders an MP section; reference apps never add sections the MP does not have.
3. **Receipt:** for each screen touched, one row: MP page path → native view file → MP sections present (✓/added) → optimizations applied.
Native-a/b, polish-search, i18n and debt lanes follow this too: if a screen you touch is missing an MP section or has it out of order, fix that first.


## OWNER RULE 2 (11-27 ~14:25 UTC) — app, not mini-program: native navigation + ONE design system
"Although the structure references a mini-program, it's an app overall, so it lacks the mini-program's navigation, making it different. We need to use the original styles and components as much as possible (unless it's the optimized version I sent you before), and all pages should have consistent logic and patterns—this includes things like fonts, letter spacing, and the top-left title. The design system cannot be haphazard."
- **MP decides WHAT is on a page** (sections, order, fields, states, copy, destinations). It does **not** decide navigation chrome or look: never copy MP custom nav bars, capsule-avoiding buttons, banners bleeding over the title, or wxss/rpx pixel values.
- **Navigation is native app navigation, the same everywhere:** tab bar; every tab root = `NavigationStack` with the **large title top-left** (`.navigationTitle` + `.navigationBarTitleDisplayMode(.large)`); every pushed page = inline title; MP popups/half-screens = `.sheet` with detents; toolbar items in the standard places (settings/more top-right, back top-left).
- **Styles/components = Apple system ones, or the owner-approved native-r2 design system** (`App/DesignSystem`, `App/NativeR2/Components`, design board be610294). Nothing per-page.
- **One type system:** text only through Dynamic Type text styles (`.largeTitle … .caption2`) and the shared CY wrappers; **no `.font(.system(size:))`, no `.tracking`/`.kerning`, no custom font names** on player screens. One button system (`.borderedProminent` primary / `.bordered` secondary / `.borderless` tertiary or the CY equivalents), one list/card/empty/loading pattern.
- **Corrects the 13:34 Home note:** keep the large top-left title 首页 (no banner over the nav); the MP order applies to the content under it (banner → greeting/city → location card → 编辑精选 → 附近活动 → 即将上线 → feed tabs). Lanes that moved a banner under a transparent nav bar must restore the standard large title.
