# Mini-program image mapping

Handoff for restyle agents. The app UI stays native Apple. This pass does not edit screens and does not put the images into views.

Catalog: `App/Assets.xcassets/MP/<category>/<asset>.imageset`. Accessors: `App/MPAssets/MPAsset.swift` (`MPAsset.<Group>.<name>`).

SVG sources are imported as vector PDF converted from the original file. The artwork is not redrawn. Bitmap sources had no `@2x` or `@3x` filename, so each bitmap imageset holds the original file in one universal 1x slot.

System-control glyphs stay SF Symbols: back chevron, close ✕, share, more ⋯, and search magnifier. The mini-program ships no back-chevron image and no more-⋯ image; those controls stay the system back button and `ellipsis`. Rows for close, share, search, and the disclosure chevron say so in Action.

Action is `use this MP asset` for brand, feature, badge, illustration, marker, and tab icons, and for banner, avatar, and other shipped artwork that is not a system-control glyph.
