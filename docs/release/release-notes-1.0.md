## Known limits in 1.0

- Payouts and withdrawals are off. There is no way to withdraw money in this version.
- No in-app purchases or virtual goods.
- Password sign-in is not part of the release build.
- Mainland China service only; no US service.
- Unknown values show "—", not 0.
