## What the China reviewed deployment calls

`ChinaReviewedRouteCapability.admitsChinaProductionCall` is the admission check.
`RegionalLaunchConfiguration.makeComposition` wraps the reviewed deployment transport in
`ChinaReviewedProductionTransport`. `URLSessionTransport`, `ResponseLimitedHTTPTransport`,
and the direct China-capable sessions call `refuseUnwiredChinaProduction` before any bytes leave.
A refused request throws `APIError.notConfigured` and does not fall through to sample JSON.

The default `Base.xcconfig` build uses `shippedComposition`, which passes `reviewed: nil`
when the base URL is empty. That composition stays `.unconfigured`. It does not install a
backend. The wrapper is not what keeps that build dark: the empty URL does.

Of the 608 live call sites, 592 are eligible. Sixteen stay off. Those sixteen expand,
with the fifteen live prefixes, to 658 production patterns the deployment may call.
A prefix admits a child only when that child is itself a production mapping. Missing
literals under `/api/play/` and the other prefixes are not in the 658.

## Hidden by capability

China verifies only `.domesticChinaPhone`. The following stay hidden because their
capability is not available, and the route gate refuses them even if a caller builds the URL.

- Password login (`.usernamePassword`): `/api/login`. Phone, Apple, and WeChat app login stay eligible when live.
- Bank withdrawal (`.merchantPayout`): `/api/withdrawal/create` and `/api/fund/preflight/**`. `/api/withdrawal/list` is history and stays readable. Team leave, offer withdraw, and chapter-application withdraw are not bank payouts.
- Virtual goods (`.digitalContentPayment`): `/api/cart/**`, `/api/product/info`, `/api/product/list`, `/api/registration/pay`, `/api/registration/pay/app`. `/api/pay/create` is missing, so it is hidden too.

The other 385 missing call sites have no capability that shows them. `isHiddenFromChinaReviewed`
is true for every path the gate refuses. United States `apiBaseURL` stays empty. No US host is invented.

This change does not deploy, does not refresh the CI ledger, and does not add mock payloads
on the production path.
