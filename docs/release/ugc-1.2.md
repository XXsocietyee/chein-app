# App Store Guideline 1.2 (User-Generated Content) Completeness

## Shared Infrastructure

- **Mini-program report taxonomy (`GET /api/v1/community/capabilities`)**: `UGCContentSafetyHTTPService.fetchCapabilities(token:)` in [`Core/UGCContentSafetyService.swift`](../../Core/UGCContentSafetyService.swift#L134) reads `reporting.reasons[].{code, label, priority, emergency}` (13 mini-program categories including `DANGEROUS`, `MINOR_SAFETY`, `SELF_HARM`, `SEXUAL_CONTENT`, `HARASSMENT`, `HATE`, `FRAUD`, `IMPERSONATION`, `FALSE_INFORMATION`, `SPAM`, `PRIVACY`, `INTELLECTUAL_PROPERTY`, `OTHER`) and drives [`UGCReportSheet`](../../App/UGCSafetyComponents.swift#L278).
- **Cross-surface block & hide (`POST /api/im/block`, `POST /api/im/unblock`, `GET /api/native/blacklist/list`)**: [`UGCBlockedUsersStore`](../../Core/UGCContentSafetyService.swift#L423) persists blocked `memberID`s and author names per `(accountID, realm)`, synchronizes server blacklist entries via `GET /api/native/blacklist/list`, syncs channel-scoped block lists via `ChannelBlockedUsersStoring`, and reactively hides content across feeds, comments, chats, and reviews via [`UGCBlockedFilterContainer`](../../App/UGCSafetyComponents.swift#L173).
- **Content filter & moderation**: [`UGCContentSafetyHTTPService`](../../Core/UGCContentSafetyService.swift#L134) (`POST /api/ai/safety/precheck`), [`ChannelContentFilterHook`](../../Core/ChannelDiscordMessaging.swift#L1322) (blocked senders, muted keywords, objectionable-content masking), and [`PublishTopicAndCommentModerationSectionView`](../../App/PublishTopicAndCommentModerationSectionView.swift#L133).
- **Published contact info**: [`SettingsSupportSafetyEntry`](../../App/SettingsSupportSafetyEntry.swift#L15) and [`WithdrawalSupportContactView`](../../App/WithdrawalSupportContactView.swift#L14) (`GET /api/play/contact`), also linked directly inside [`UGCReportSheet`](../../App/UGCSafetyComponents.swift#L278) and [`UGCSafetyMenuButton`](../../App/UGCSafetyComponents.swift#L563).
- **Session injection**: [`AppSession.makeUGCSafetyContext()`](../../App/UGCSafetyComposition.swift#L23) injected into the SwiftUI environment in [`QuestifyApp.swift`](../../App/QuestifyApp.swift#L432).
- **Dual grant lists**: Verified in both [`Core/ChinaReviewedRouteCapability.swift`](../../Core/ChinaReviewedRouteCapability.swift) and [`App/ReviewedPlayerWriteLeases.swift`](../../App/ReviewedPlayerWriteLeases.swift#L714).
