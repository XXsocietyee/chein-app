# U10 playkits receipt (ui/u10-playkits)

Follow-up to U9 (F95, F103, F104, F46, F82 and the sheet-over-pack rule left in `u9-f.md`). Base: `origin/ui/next` `fd8ddfe57`.

Code only. No xcodebuild or simulator run in this lane; the integrator compiles. Every changed Swift file passed `xcrun swiftc -parse`. The three new App/Core files (`PlayKitQuestoContracts.swift`, `PlayKitQuestoViews.swift`, `PlayKitAlbumView.swift`) also passed `swiftc -typecheck` for iOS 17 against small local stubs of the design system and `PlayAdvancedState`. That is a stronger check than parse, but it is not a module build. `tools/generate_project.py` was run (files added). `tools/check_scaffold.py` and `tools/check_design_lint.py` pass. Mini-program screenshots were compared locally and are not committed.

Copy is en + zh-Hans in `Resources/Localizable.xcstrings`, taken from the mini-program zh source (`tools/add_u10_playkits_localizations.py`, idempotent). The `playkit.*` keys are also in `Resources/PlayKitScreenLocalizations.fragment.json` and `docs/playkit-screen-localizations.json`. Colours use CYColor and CYNight only. Unknown values show an em dash. Every moving piece has a Reduce Motion fallback (`QuestifyReduceMotion`). Money, merchant and password paths are untouched. UG-01 and UG-03 writes stay NOT_RUN.

- `PlayAdvancedState.accusation` / `.clues`: decoded from the advanced view's `accusation` and `clues`. When absent, the accusation screen stays hidden and the qa form shows.
