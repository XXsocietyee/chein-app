Branch `ui/prmount` from `origin/ui/main`. Plan: `ui/docinv` `docs/release/receipts/docs-inventory.md` B1 row L8 and headline 5. Core, network and reducers were not edited. `ui/mpmissing` / `ui/mppass` files (`OrientScoreView.swift`, `TeamOrientBoardView.swift`, `AccountView.swift`, `GlobalSearchView.swift`, …) were not touched.

## For Cursor (logic / composition)

1. `CityFairnessEntryBinding.makeReader`: build a `CityFairnessReader(approval:transport:isCurrent:onUnauthorized:)` from the session's runtime context. Return nil when there is no reviewed `CityFairnessReadApproval`.
2. `OrientScoreEntryBinding.makeLoader`: port mini `_resultEntry()`. That means signed-in reader, `memberId` match, registration topic, `activityId` (`ownerType == 1` → 0), and `productType == 1`. Return a closure that calls `OrientSessionService.score(sessionID:scope:token:)`. `ParticipationDetail` does not expose topic/activity/productType today.
3. `merchantAuthoringDestination`: create a `MerchantAuthoringCoordinator`, call `adopt` with account / merchant / store / permission revision, and set the env on `MerchantHomeView`. The view still has zh-only literals that need catalog keys.
4. Perks writes: pass a `CoopFlowDormantExecutor(service:)` to `MerchantPerkTemplatesHost(reader:executor:)` once `api/coop/perk-template/save|delete` are approved. That shows add and delete.
5. `MyProjectMutationFactory.makeMutator` and `TopicTemplateUseFactory.makeUser`: set them once the routes are allow-listed. Topic cancel needs the mini `cancel_preview` flow, which has no native model yet, so the row menu offers cancel for activities only.
6. `topicTemplateCopiedDestination`: open the topic editor for the copied `topicId`.
7. `OrientScoreReviewFactory.makeSubmitter`, then embed `OrientScoreReviewSection` (layout, after `ui/mppass` merges).
8. Search map capsule and offline banner: these need a reviewed re-pin of `test_global_search_category_recovery.py`.
9. H5 shells: they need a production `H5LaunchProducer` / install reader before any mount.
