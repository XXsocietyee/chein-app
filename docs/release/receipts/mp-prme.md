# mp-prme — L2 Me / Passport / Settings page models (layout side)

Branch `ui/prme`, base `origin/ui/main` (3b319cbb9). Source of truth: `liboyang42-cpu/hengyin` `chengyinhub-xcx` (current). Plan: `ui/docinv` `docs/release/receipts/docs-inventory.md` row L2 and the page-ready docs it cites.

Code only. Nothing was compiled, and no simulator or `xcodebuild` was run; the integrator compiles. Core, network, reducers, and tests were not edited. Every new file-level type sits in an existing App file, so `tools/generate_project.py` produced no project change. `tools/check_design_lint.py` and `tools/check_scaffold.py` pass. The Python contract suite (`Tests/ContractChecks`) shows no new failures against `origin/ui/main` (see the end of this receipt).

Payments, payout, withdrawal, and virtual goods stay off. `showsMerchantChoice` stays false. No safety gate, legal body, support contact, ICP, or UGC placeholder changed. No mock data was added to production paths. Every existing accessibility identifier was kept.
