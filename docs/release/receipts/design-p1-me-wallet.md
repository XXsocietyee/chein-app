# design/p1-me-wallet — lane L8 (Me, orders, tickets, wallet) receipt

Base: origin/ui/combined-r7. Checked origin/fix/backlog-p0, native-r2/island-r1, native-r2/motion-r1 and native-r2/sheets-r1 first: none of them changes an L8 file, and island-r1 and motion-r1 are already in combined-r7. Strings: `docs/port/strings/native-r2-l8.json`, merged into `Resources/Localizable.xcstrings` (51 keys, en + zh-Hans). Gates: `check_scaffold.py` PASS structural checks; `check_a11y_lint.py` PASS (0 new). No compiler run in the cloud, so the app has not been built.

- G-047 done — `MemberSignOutConfirmSheet` is gone. Sign-out now uses the system `.confirmationDialog`, in a shared modifier `memberSignOutConfirmation(isPresented:presenting:message:confirmIdentifier:onConfirm:)` in App/MemberAreaPopupSurfaces.swift. It is used in AccountView and SettingsAccountEntries (Settings was the same custom sheet). `presenting:` keeps the account snapshot taken at tap time. The `auth.signOut.confirm` and `settings.signOut.confirm` identifiers are kept. The fixture shows the dialog.
- G-048 partial — 47 inline `MemberPopupCopy.text("zh","en")` literals in MemberAreaPopupSurfaces.swift now use `appLocalized("memberPopup.*")`; 2 of them are interpolated and use `%@` with `String(format:locale:)`. The 4 `DeepLinkSceneDiscardPrompt` lines stay as they were because their zh text comes from Core (`NPCChatRecordsHelper.swift`) and Core behaviour is out of scope. `MemberPopupCopy.text` uses in other files belong to other lanes.
- G-052 done — Orders has `.searchable` that filters only rows already on screen (title, registration/order number, place, ticket, organizer). It makes no request and the list keeps server order. Search runs after the status filter and uses `ContentUnavailableView.search` when nothing matches. Paging pauses while a search is active. The true-empty state is now an empty `List` with an overlay, so `ProfileReadScreen`'s existing `.refreshable` also works there; non-empty lists already had it. Row changes animate, with no animation under Reduce Motion.
- G-053 done — The order filter is now one system `Picker` with `.pickerStyle(.menu)`, offering the nine MP options in MP order. It replaces the horizontally scrolling `OrderFilterPill` capsule row. The SF Symbol fills when a filter is active (`.contentTransition(.symbolEffect(.replace))`), and there is `.sensoryFeedback(.selection)`. The `profile.orderFilter.picker`, `chip.<raw>`, `empty` and `clear` identifiers are kept. `test_w2_04_orders`, `test_profile_order_filters` and `test_c11_ops_support_projections` were updated to match, and so was `ProfileOrderFilterFlowTests.choose`, which now opens the menu.
- G-056 partial (no server .pkpass) — No ticket or order contract carries a signed pass, and this lane adds no request. New App/TicketAppleWalletPass.swift adds `TicketAppleWalletPassButton`, which wraps Apple's `AddPassToWalletButton` (the SwiftUI `PKAddPassButton`). It is controlled by the environment hook `ticketAppleWalletPassData` (nil by default) and by `PKAddPassesViewController.canAddPasses()`. It sits under the pass in TicketPassSheet and renders nothing until a host provides pass bytes. On add it shows an IslandCenter `.status(.success)` pop-up, or posts a VoiceOver announcement when the island flag is off, and plays a success haptic.
- G-058 done — In TicketPassSheet, the empty, signed-out and server-error states are system `ContentUnavailableView`s. They keep the same copy and the `cy.state.*` identifiers, and they now support pull-to-refresh.
- G-059 done — The coupon QR (CouponCodeView) raises the screen to full brightness while the code is scannable (`phase == .ready && canDisplay`). It uses the same `cyBrightnessBoost` helper as the ticket pass, which sets brightness instantly under Reduce Motion and restores it on leave or background.
- G-060 done — BankWithdrawalView is now a system `Form`: sections with header and footer, `TextField`/`SecureField`, `LabeledContent` in the review sheet, a `Label` status line, `ProgressView` in place of `CYSkeleton`, and a bottom bar holding the one prominent button. It uses the system sheet (`cyPlayerSheetGlass` removed) and `.sensoryFeedback`. Money is unchanged: the same `adapter.isAvailable`/`hasUnresolvedOutcome`/`busy`/`review == nil` gates, `interactiveDismissDisabled(true)`, clearing, and identifiers.
