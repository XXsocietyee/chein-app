## Wiring

- `PlayExperienceService.help` reads with the `.reads` grant and writes with the existing reviewed `.hints` grant. `api/play/help/use` and `api/play/help/skip` were added to `ReviewedProductionGateLeases.playPaths` so the reviewed player transport covers the two POSTs. No new money path; points are the existing redeemable points ledger.
- `PlayExperienceCoordinator.helpClient(nodeID:)` returns nil without a route session id, a current read, or both grants. Advanced-session receipts (`/api/play/help/advanced/receipt`) are not wired, matching the mini-program.
- `UGGameplayReader` stays a decoder-only read client (unused by the app); its `useHelp`/`skip` stubs are unchanged.
