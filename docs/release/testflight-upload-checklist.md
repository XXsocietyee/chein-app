## 1. Before you open Xcode · 打开 Xcode 之前

- [ ] `git fetch && git checkout` the branch you intend to ship (the merge of `ui/combined-r7` with this lane and Lane G).
- [ ] `python3 tools/check_scaffold.py` ends with PASS lines and no FAIL.
- [ ] `python3 tools/contract_ratchet.py --check` reports no new failures.
- [ ] Lane G (`claude/player-release-gate`) is merged, so the merchant center, onboarding and coop entries are hidden in Release. If it is not merged, merchant tools are reachable in this build.
- [ ] App Store Connect > Apps: the app record (Apple ID `6832441069`) has bundle id `com.chengyinhub.chengyinApp`.

## 2. Signing · 签名

- [ ] Xcode > Settings > Accounts: sign in with the Apple ID that is Admin or App Manager on the developer team.
- [ ] Open `Questify.xcodeproj`. Target **Questify** > Signing & Capabilities: **Automatically manage signing** on, pick your team. Do the same for target **QuestifyLiveActivity**.
- [ ] Capability **Sign in with Apple** shows on the Questify target (from `Config/Questify.entitlements`). Automatic signing registers it on the App ID.
- [ ] Do not commit any change Xcode makes to the project, a team id, a `.p12`, a `.mobileprovision` or an API key. The repo is public. If Xcode edits `project.pbxproj`, discard that change after archiving (`git checkout Questify.xcodeproj`); the project is generated by `tools/generate_project.py`.

## 3. Archive · 归档

- [ ] Scheme **Questify**, destination **Any iOS Device (arm64)**.
- [ ] **Product > Archive**. The first build phase, **Release Identity Gate**, stops the build if the host, realm or bundle id is empty or a placeholder.
- [ ] Organizer opens with the archive; Version 1.0.0 (2).

## 4. Upload · 上传

- [ ] Organizer > select the archive > **Distribute App** > **App Store Connect** > **Upload**.
- [ ] Keep: automatic signing, upload symbols (dSYM), manage version and build number **off** (the repo owns them).
- [ ] Wait for the "has completed processing" email (usually 5–30 min). The build appears under App Store Connect > the app > **TestFlight** > iOS Builds.

## 5. Export compliance · 出口合规

`ITSAppUsesNonExemptEncryption = NO` is in the Info.plist, so App Store Connect should not ask. If it does ask (for example on an older build):

| Question | Answer |
|---|---|
| Does your app use encryption? / 你的 App 是否使用加密？ | Yes, only exempt encryption: HTTPS through Apple's networking, and Apple CryptoKit (AES-GCM, SHA-256) to protect the app's own local data. No proprietary or non-standard algorithm. |
| Does it qualify for an exemption? / 是否符合豁免？ | Yes: uses only encryption available in Apple's operating system / standard HTTPS. Select "None of the algorithms mentioned above" when asked about proprietary or non-standard algorithms. |
| France / 法国 declaration | Not needed (not distributed there by this build). |

Evidence: `Core/ContentDraftDurableJournal.swift` and `Core/PlayDurableRecovery.swift` use `CryptoKit` `AES.GCM` for on-device journals; all network traffic is HTTPS (no ATS exception in `Config/Info.plist`).

## 7. What to test first · 首测清单

Production backend: use test accounts, small amounts, and refund what you buy.

1. [ ] Install from TestFlight; first launch shows the usage-consent gate; Browse enters the tab shell.
2. [ ] Settings > About shows Version 1.0.0, Build 2.
3. [ ] Sign in with Apple; SMS sign-in; sign out; password login is absent.
4. [ ] Permission prompts appear in your device language (zh-Hans and en) with the new texts: location (roam / I've arrived), camera (QR scan, stamp photo), microphone (IM voice), photos add (save a walk card), motion (step count).
5. [ ] Roam: start a walk, lock the phone for 2 minutes, unlock; the route kept recording and the location indicator showed; finish stops it.
6. [ ] Play a self-play topic end to end (start, a node, ending).
7. [ ] Money: buy a low-price event ticket, see it in Orders and the ticket wallet, then refund it; check the refund state. If you host a club event, cancel it and check the host-cancel refund.
8. [ ] Virtual goods are not offered: platform pass, seat packs and paid templates show no buy button.
9. [ ] Merchant center, merchant onboarding and coop entries are not visible from Me, Settings, search or a deep link (needs Lane G).
10. [ ] Delete-account entry exists in Settings (do not complete it on a real account).
11. [ ] Live Activity appears on the Lock Screen during a roam walk.

Report problems in TestFlight (screenshot feedback) or to the repo with the build number.
