# 社区规范

城瘾（Chein）**0.1.0 (1)**。简体中文。英文文本是 [`community-guidelines.md`](community-guidelines.md)。怎么答复对方写在 [`support-playbook.zh-Hans.md`](support-playbook.zh-Hans.md) 和 [`support-playbook.md`](support-playbook.md)。

这些说明告诉客服可以怎样描述社区行为。它们不是用户协议，不是隐私政策，也不是 App Store 提交材料。它们不改版本。营销版本保持 `0.1.0`，构建号保持 `1`。

状态：**占位**。这段保持原样。不要在里面起草政策。

```

```

所有人还没有提供用户生成内容政策、用户协议里的令人反感内容条款、审核时限，或负责审核的人。不要把「设置 → 客服与安全」里的草稿贴进这块。不要把俱乐部分会频道的规则句子贴进这块。不要写审核时限，包括 24 小时。

在所有人替换这个占位之前，客服只用下面的操作说明，并说明正式的用户生成内容政策尚未公布。

用户协议、隐私政策和注销须知的法律文本是另一块占位：`[LEGAL_TEXT_PLACEHOLDER]`。本规范不是那段文本。

## 适用于谁

在城瘾里探索、发帖、评论、发消息、参加俱乐部和活动的人。商家和俱乐部组织者在这些空间里发内容时，同样适用。

## 操作说明

这些是答复时用的内部规矩。它们不是用户生成内容政策。

- 尊重其他人。骚扰、威胁和仇恨攻击不可接受。
- 不要发布别人的私人信息，包括电话号码、地址或身份证件。
- 不要发布涉及未成年人的性内容。遇到就举报。客服不索要该内容的副本。
- 不要发垃圾信息、行骗，或冒充 App、其工作人员或其他人。
- 不要用社区空间出售虚拟商品或收集银行卡信息。这两项在 0.1.0 (1) 都保持关闭。
- 定位只在 App 打开时使用，并且是对方选择了定位功能，或向选定的人开始个人共享时才使用。不要为了无关的理由让任何人在后台一直开着定位。

## 举报与屏蔽

只有屏幕上已经有举报动作时，才让对方使用。

- 广场动态和评论的溢出菜单里有「举报」。在动态里屏蔽会告诉对方暂不可用，而且没有屏蔽任何人。照这个说。不要说屏蔽已经成功。动态屏蔽的提示还说明可以举报这条内容，或在聊天里屏蔽对方——仅当那个聊天已经显示该动作。
- 俱乐部分会频道已经为频道、消息和成员提供举报动作。用那些。不要把该屏幕上的规则页当成本文的用户生成内容政策，也不要从里面重复一个时间承诺。
- 俱乐部帖子和评论，以及商家评价，用该屏幕上已经有的举报动作。
- 在「信息」里，只有会话本身已经提供举报和屏蔽时才使用。只提供隐藏的通知保持原样。

这些屏幕没有举报入口。不要编一个按钮：

- 主题详情
- 主题评价与分区
- 活动评价
- 俱乐部帖子讨论评论
- 成员头像

这些情况由对方向客服描述内容。客服记下来。客服不承诺会删除，也不给时间，因为审核由谁负责写在 `[UGC_POLICY_PLACEHOLDER]` 里。

屏蔽动作在屏幕上完成时，作用于这个人自己看到的内容。它本身不是对所有其他人的封禁。除非所有人的流程已经记录了封禁，否则不要说某人已被封禁。本文不定义那个流程。

## 0.1.0 (1) 不提供的内容

密码登录保持关闭。不要让对方设置密码或用密码登录。

银行卡提现保持关闭。社区空间不是收集卡号或承诺转账的地方。

虚拟商品保持关闭。社区空间不是它们的商店，客服也不出售它们。

版本保持 0.1.0 (1)。
