The 112 failures reproduce in isolation, so they are real, not cross-test pollution. Chunk logs: `/private/tmp/gm-intc-audit-core-r*.log`.

Runs inside the agent sandbox cannot reach testmanagerd (`/private/tmp/gm-intc-audit-appunit2.log`: Operation not permitted), so these ran in Orca terminals.
- Evidence per row = the tests named in the notes/proof table plus test classes whose file name matches the row's view/service types (name-matched, not hand-verified against each assertion). Rows with no executing test found would be reverted; none had zero.
