## 1. Architectural Summary: Why Capsule Layout Exists in Mini-Program & How iOS Replaces It

In WeChat Mini Program (`chengyinhub-xcx`), `"navigationStyle": "custom"` is set globally in `app.json`. Because WeChat permanently overlays a hardware-like capsule button (`•••` menu + `⊗` close mini-program, queried via `wx.getMenuButtonBoundingClientRect()`, typically `87×32pt` anchored `7–12pt` from the right screen edge), the mini-program had to work around three structural constraints:

1. **Right-Top Dead Zone (`actionsRight` / `capsuleRightGap` ~ `96–108pt`)**:
   - Every custom navigation bar (`components/cy/nav-bar`) and top-bar header (`pages/index/index`, `subpackageB/pages/im/list/index`, `pages/talent/list/index`, `pages/template/index`) had to shift its trailing buttons (`slot="actions"`) left by `windowWidth - menuButton.left + 12px` so they wouldn't collide with the WeChat capsule.
   - To keep centered titles from colliding with shifted right actions, `cy/nav-bar` enforced symmetric left/right title insets (`Math.max(leftInset, rightInset + actionsWidth)`) and hid the title completely whenever the remaining center corridor dropped below `96px`.
2. **Sheet Top Push-Down (`resolveMenuChrome(...).sheetTop = menuButton.bottom + 5px`)**:
   - Full-height sheets (`cy/sheet`, `cy/scene-sheet`, `cy/date-sheet`, `post-compose`, `story-sheet`, `fabu` sub-sheets) could not extend into the normal top safe area because a user tapping the sheet's top-right `关闭` / `完成` button could accidentally hit WeChat's `⊗` button and kill the entire mini-program session (losing unsaved drafts).
3. **Floating HUD & Camera Control Avoidance (`contentTop = menuButton.bottom + 12px`)**:
   - Map overlays (`pages/roam/index`, `pages/searchmap/index`, `subpackageRoam/nearby/index`), camera views (`cy/proto-cam`, `subpackageRoam/citystamp/index`), and game HUDs (`pages/play/index`, `pages/play/poi-challenge/index`, `subpackageP3/pages/badge-3d/index`) manually offset their top-right controls below `menuButton.bottom`.

### Native iOS Replacement Contract (For All Tracks W4–W8)

| Mini-Program Capsule Mechanism | Native iOS Replacement (`SwiftUI`) |
|---|---|
| `wx.getMenuButtonBoundingClientRect()` & `app.globalData.menuButtonInfo` | **Delete completely.** Never reserve right-top blank space or offset trailing toolbar buttons inward. |
| `<cy-nav-bar title="..." back>` + `<cy-nav-spacer>` | Standard `NavigationStack` with `.navigationTitle(...)` and `.navigationBarTitleDisplayMode(.inline)` (or `.large` on root tab screens). System handles safe-area insets and blur material automatically. |
| `<cy-nav-bar><view slot="actions">...</view></cy-nav-bar>` | `.toolbar { ToolbarItem(placement: .topBarTrailing) { ... } }`. **Maximum 2 trailing items** per screen, each with `>= 44×44pt` hit target (`CYSpacing.minTouchTarget`). |
| WeChat Capsule `•••` (Share / Report / Favourite / More) | **Share**: `ShareLink` or `UIActivityViewController` in `.topBarTrailing`.<br>**Report / Block / More**: `Menu { ... } label: { Image(systemName: "ellipsis.circle") }` in `.topBarTrailing` or row `.contextMenu`. |
| WeChat Capsule `⊗` (Close / Exit) | **Pushed pages**: System `NavigationStack` back chevron + interactive left-edge swipe.<br>**Sheets / Modals**: System `.sheet` / `.fullScreenCover` with `.presentationDragIndicator(.visible)` and `.toolbar { ToolbarItem(placement: .cancellationAction) { Button("关闭") { dismiss() } } }`.<br>**Immersive Map / Play HUD**: Top-leading close/back pill aligned to standard `safeAreaInsets.top + CYSpacing.sm`, freeing the entire top-right corner for up to 2 HUD controls. |
| `resolveMenuChrome().sheetTop` (`--cy-psheet-max-h` / `panelTop`) | Standard `.sheet` with `.presentationDetents([.medium, .large])` and `.presentationCornerRadius(CYRadius.sheet)`. Top-right `完成` / `提交` buttons sit naturally in `.topBarTrailing` (`ToolbarItem(placement: .confirmationAction)`). |
