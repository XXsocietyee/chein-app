# 创作者入门

创作者发布路线、活动和模板，然后在「我的项目」里找到它们。发布权限来自服务器。「我的」上的一个按钮不会授予权限。本页按仓库里已经写明的小程序发布路径说明。

>
> 用户协议、隐私政策和账号注销说明没有写在本指南里。
> 审定文本尚未提供。阅读本页不算同意。
> 不要把这段占位文案当作协议放进 App。

> **[客服联系方式占位 — 尚未公布]**

> 如果没有展示，本页不能替你编一个。

## 我的项目

从「我的」打开「我的项目」。三个标签是主题、活动、模板。

- 主题和活动列出你发布的，或请你承办的内容。卡片可以显示「主办」或「承办」、有地址时的地址，以及时间。协办卡片在服务器给了数量时可以显示「待核销」。没有数量不是零。
- 需要你先处理的卡片排在前面。顺序是已驳回，然后草稿，然后审核中。
- 列表只加载一页，最多 200 条。达到上限时，页面请你筛选，而不是编出下一页。中文是「已达到200条加载上限，请筛选查找」。
- 模板标签是你自己的模板架，不是公开的模板浏览。上架、下架和删除只在对应写入打开时出现。

小程序卡片长按会列出「收到的申请」「编辑」「上下架」「取消并退款」「删除」。在 iOS 上，这项菜单里的动作要等到对应写入打开才可用。禁用的一行不是隐藏手势。

空标签各有一句说明。主题为空时可以出现「去发布」。活动为空时，只有当前会话角色是俱乐部，才出现「发布单场活动」。这个按钮打开普通发布台，并会再检查一次你能不能发布。

草稿和已驳回的主题卡片打开编辑器。公开预览是另一页。不要把预览当成编辑器。

## 一条路线，短路径

快速发布从「嗨，想做一条什么样的路线？」开始。你会看到路线类型、一份草稿，以及编了号的站点。每一站都有需要你确认的地点。

AI 草稿只是草稿。入口上的说明是 AI 只起草。站点要你自己确认，确认单里最多三站，然后才进入编辑器。主按钮是进入编辑器，不是发布。

编辑器保留本地草稿。干净的编辑器可以直接离开。改过的编辑器会问你继续编辑还是丢弃。丢弃不会删掉已经保存的草稿。如果预览开着，先关上预览。已经在提交时，编辑器不会再提交一次。

路线配额是权益里「发布路线」的那个数字，以服务器返回的为准。空值表示没有给出上限。权益读不到时，页面会说明当前配置不能读取权益。不要把这当成无上限。

## 一场活动

活动向导是三个问题：

1. 这场活动叫什么、在哪儿办？
2. 这场活动玩什么？
3. 这场活动怎么卖票？

然后是摘要。新活动写「发布前摘要」。修改写「修改摘要」。读那张卡片上的可见范围。

合作者会先并上你本人，不会把你重复一遍。说明是：合作者可编辑内容，不参与结算。

主办方是商家时，票价只能是 0。商家主办活动还没开通收款。如果你不是这家商家，票又是付费的，发布者身份必须已经登记。向导会在这里停下来检查。

确认摘要就是这个页面拥有的发布步骤。如果这项写入是关的，按钮会说明。不要再找第二条提交路径。

## 一个模板

模板介绍最多加载三个例子。有推荐就用推荐，否则用热门，否则用最新。不会把几组混在一起。加载中、加载失败和确实为空是三种状态。刷新失败会留下你已经看到的卡片。开始和跳过都可以继续，没有卡片时也一样。

接着给模板起名并编辑。介绍页上的例子不会被抄进你的草稿。

保存和发布是两步。带有真实编号的发布成功会短暂显示结果，然后打开「我的模板」，也就是你自己的架子。没有编号的结果不是成功。关掉结果不会再次发布。

干净的表单可以直接返回。改过的表单会问你继续还是丢弃。这个问题不会清掉已保存的草稿。

公开模板页和你的私有模板不是同一页。秘密答案留在私有页上。不要指望公开资料页上也有。

预演和预览只针对你写的内容。它们不发勋章，不改玩家的生命值，也不写一场真实对局。预览里的骰子例子用屏幕上给出的示例点数，不是服务器掷出的结果。

## 审核状态

项目卡片和创作者中心使用服务器的状态。它们是分开的：

| 状态 | 你要做的事 |
| --- | --- |
| 未申请 | 还没有提交申请。这和已驳回不是一回事。 |
| 草稿 | 还是你的。打开编辑器。 |
| 审核中 | 等待。不要在本地把它改成通过。 |
| 已通过 | 服务器接受了。卡片会说明你还能改什么。 |
| 已驳回 | 先读理由。卡片允许重新提交时再打开编辑器。 |
| 未知 | App 不会把这个状态改标成「未申请」。刷新或稍后再来。 |

创作者中心的收益只显示服务器带上的那个数字。没有数字就保持没有。零就保持零。本页不会把这个数字变成一笔打款、一种页面没显示的币种，或一笔余额。

「我的」里的权益在能够读取时，列出这个账号可以做的事：发布路线的上限或「不限」、发布优惠券、到店核销、分支和条件玩法、博弈机制、把店铺开放为城市节点、勋章设计、建群，以及我的收益。只有明确的「是」才会解锁一行。读取关闭时，这一节会说明当前配置不能读取权益。

## 本页不写的内容

密码登录不是创作者工具。这里不用银行卡提现来支付创作收益。虚拟商品不是一种发布类型。你挂在路线上的优惠券，是玩家到店出示的权益，不是在 App 里出售的道具。

上传图片、下架和取消并退款，以 App 已经打开的控件为准。长按菜单上没有启用的一项，不会发生任何事。

## 页面不动的时候

- 从按钮打开的发布台去发布。发布台会再查一次权限。玩家会话上看不到只给俱乐部的活动按钮。
- 结果未知时不要再次提交。打开「我的项目」读卡片。
- 模板编号、主题编号和活动编号可以数字相同，仍然是不同的东西。从你出发的那个标签打开。
- 200 条上限是停住，不是列表坏了。用筛选。
- 游客和未登录状态不会加载这个架子。登录后再打开「我的项目」。
