# 俱乐部入门

俱乐部是在一座城市里承接路线和活动的团体。你可以先以游客浏览，再以成员加入，或申请成为主理人。创建俱乐部是后面的一步，而且要等服务器标明这个账号已经是主理人。

本页按仓库里已经写明的小程序俱乐部路径说明：俱乐部首页、加入或申请、俱乐部页、主理人申请，以及创建。

## 找到一个俱乐部

俱乐部标签分成四组，彼此不是同一份列表：

- 我创建的俱乐部 — 这个账号创建的。它不是你加入的那些。
- 我加入的俱乐部 — 你已经属于的。
- 附近俱乐部 — 作为附近返回的。
- 俱乐部活动 — 挂在俱乐部上的活动。App 有去处时，一行会打开那场活动。否则它就只是可读的一行。

「查找俱乐部」按名称搜索。不填名称就是目录。没有匹配时写「未找到俱乐部」。换一个名称，或清除搜索。

我创建的、我加入的、附近的，可以各自为空。空不是错误。加载失败才有重试。401 会要求登录。403 表示这个账号不能看这一页。重新登录不能解决 403。

成员名单给创建者和已经加入的人看。访客看不到。俱乐部写明有成员，名单却是空的，这时名单是暂未获取，不是「这个俱乐部没有成员」。

## 加入、申请或退出

俱乐部页上的按钮取决于入会规则和你现在的状态。App 会在请你确认之前再读一次俱乐部，发送之前再读一次。

| 你看到的 | 会发生什么 |
| --- | --- |
| 加入俱乐部 | 你请求加入。是不是成员，以下一次详情回读为准。第一次返回不会在设备上把你标成成员。 |
| 申请加入 | 这个俱乐部需要审批。你等待。待审批时再发一次不会提交第二份。 |
| 重新申请 | 上一次申请被拒绝了。可以再发一份。 |
| 退出俱乐部 | 你是成员，且不是创建者。确认后退出。你可能再也看不到成员名单和成员专属功能。重新加入可能需要审批。 |
| 待审批 | 申请在等。没有第二次提交。 |
| 创建者 | 创建者不能用这个按钮退出自己的俱乐部。 |
| 商家账号 | 商家账号不能用这个按钮加入俱乐部。页面改走合作路径。 |

结果未知时不要再发一次。请求可能已经到达。用「查看当前成员状态」，再读详情。回读之后，已加入、待审批和不是成员仍然是三种状态。

首页上只对俱乐部开放的活动会写「请先加入俱乐部再报名」。先加入那个俱乐部，再回到活动。名额也可以为会员保留。

这个加入按钮上没有会员费。服务器拒绝了请求，拒绝就成立。本页不另开一条进入方式。

## 俱乐部里面

俱乐部页有帖子、活动、概览。主理人或管理员还能看到管理。访客或正在查看的商家账号落在概览。成员落在帖子。详情回读写明你不能管理时，不能强行打开管理。

概览有简介、主理人、城市、类型，以及你有权查看时的成员入口。本周贡献榜给成员看。不是成员的人会看到它锁着，而不是一份零的榜。

活动列出俱乐部的场次，也可以打开日历。帖子是俱乐部里的会话。你能进入俱乐部之后才看得到频道。允许发言时，文字频道可以写。公告频道是只读的。你看着对话时，记录会刷新。源流程里没有另一条实时通道。

消息菜单提供举报和屏蔽时，用它们标记一个人或一条消息。不能举报自己。管理员的移出、封禁和删除不是成员操作。平台作出的封禁，俱乐部管理员不能解除。

## 成为主理人

从首页主视觉「成为俱乐部」、设置里的「成为俱乐部主理人」，或创建页写明你还不是主理人时进入。创建页会写「请先成为俱乐部主理人」，并提供「前往申请」。

申请要填：

- 实名 / 昵称
- 联系方式
- 身份说明
- 联合创始人
- 最大带队人数
- 平均参与人数
- 持导游 / 旅游资质

证书图片在上传可用之前不放进这张表。如果你加了图片而页面拦住提交，就去掉图片只发文字，或等到上传打开。不要手填一个替代网址。

商家账号和已经是主理人的人，在这张表上看到的是他们自己的状态。提交不会创建俱乐部。它是请服务器承认你是主理人。去读它返回的状态。不要把回执当成俱乐部已经存在。

小程序里的介绍、分步和完成页，在 iOS 上是一张核对表。完成页的「创建我的俱乐部」在这个衔接可用时才出现。页面上没有它时，等状态写明你已是主理人，再从俱乐部标签进入创建。

## 创建俱乐部

创建先查两件事：这个账号的角色是俱乐部主理人，以及「我创建的俱乐部」还没到两个的上限。任一不成立，表单不会打开。

小程序分四步：类型、最多三个方向、资料、城市。iOS 用一张表收集同样的必填项。类型、名称和城市是必填。

这张表不能上传标志和封面。页面会说明媒体不可用，并保留服务器已经有的引用。不要粘贴图片地址。

服务器接受创建之后，打开这个俱乐部。详情回读写明你可以管理时，才会有管理标签。如果这个衔接还没接上，从「我创建的俱乐部」打开它，再自己点管理。

## 经营俱乐部

管理给主理人，以及服务器标明可以管理的人。不是主理人的管理员可以改展示信息。卡片写的是「你是管理员 · 只能改展示信息」。优先报名、入会审批、保留名额这些经营开关属于主理人。管理员看得到当前值，没有开关。那一行是「只有主理人能改经营配置」。

管理里，入口出现时可以打开：

- 入会申请。只能对服务器列出的那一条同意或拒绝。
- 带角色的成员名单。主理人，以及仍有有效角色指派的成员，不能被移出。
- 公告。
- 组队码。只有主理人和核销人员可以出码。其他人看到「仅主理人和核销人员可出码，请联系俱乐部主理人开通」。本页不印出码。
- 一场俱乐部场次的报名册。行上可以是「已核销」或「待核销」。费用那一行写明报名费由平台担保托管。这句话不是打款说明。
- 本周数据和治理收件箱。不是管理者的人也可以从概览进入案件和申诉。
- 一条新的俱乐部路线。主理人选择城市定向或自由探索，也可以取消。打开编辑器不会发布。如果还留着一份更早的本地草稿，编辑器会问你恢复还是丢弃。恢复不会悄悄用新的俱乐部草稿换掉它。

玩家的核销详情在服务器给了步骤时，点亮「已报名」「已接洽」「已核销」「已评价」。已退款和未知步骤不点亮这条轨道。清退并退款是另一项主理人操作。对应写入打开之前，它保持关闭。不要把详情页本身当成退款。

俱乐部管理里的结算是可以阅读的对账。它不是银行转账。本指南不说明银行卡提现。

## 页面不动的时候

- 首页、目录和详情可以让游客加载。「我创建的俱乐部」和成员名单会先要求登录。
- 加入和退出会确认俱乐部名称和后果。提示和发送之间规则变了，App 会取消这一次。刷新后再读按钮。
- 别人那一行上的徽章是对方的角色，不是你的。
- 创建上限是两个俱乐部。表单不会打开第三个。
- 无法识别的入会状态会关掉按钮。去刷新。不要猜刚才会发出哪一个动作。
