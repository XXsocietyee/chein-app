## Placeholders

Every guide carries two visible blocks:

- **[LEGAL TEXT PLACEHOLDER — NOT APPROVED]** — user agreement, privacy policy, and account-cancellation notice are not written here.
- **[SUPPORT CONTACT PLACEHOLDER — NOT PUBLISHED]** — no address, phone number, email, WeChat ID, or filing number is published here.

If the app shows a contact that the server supplied, use that contact. This folder does not invent one.

## Left out on purpose

These guides do not describe password sign-in, bank-card withdrawal, or virtual goods. Those stay off. They also do not add a payment address, a US API address, or a China ICP number.

A button in the iOS app appears only when that build and the server both allow it. A missing button means that step is not available, not that this page skipped a trick.

App marketing version stays `0.1.0` (`1`).
