# IWP-3 new localization strings

Table: `BundleRefundQuote` (new `BundleRefundQuote.xcstrings`; NOT created by this WP — Resources are off limits; the orchestrator adds it).
Copy is a draft for owner review; zh-Hans is the primary locale. Server `reason`, amounts, ratios and policy version are shown verbatim and are not localized.
